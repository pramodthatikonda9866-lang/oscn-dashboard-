🎓 5. Faculty Evaluation Reference (OS Concepts & Implementation Q&A)

Q: Why import threading?

To create and coordinate concurrent execution threads in Python representing simultaneous student requests.

Q: What does threading.Lock() do?

It creates a mutual-exclusion (mutex) lock primitive. Only one thread can acquire the lock at any instant; all competing threads are put into a waiting state until the lock is released.

Q: What is a Critical Section & Race Condition?

A Critical Section is the code region that accesses shared mutable state (checking book copies and writing transactions). A Race Condition happens when unsynchronized threads interleave reads and writes, resulting in two students obtaining the same physical copy.

Q: Why use 'with book_lock:' context manager?

It guarantees that the lock is automatically released whenever the block exits—even if an unhandled exception or database rollback occurs—preventing deadlocks.

Q: Why combine Python Mutex Synchronization with SQLite Database Transactions?

The mutex protects in-memory concurrent thread execution paths from simultaneous entry, while SQLite ACID transactions and foreign key constraints ensure disk persistence consistency and atomic rollback.
